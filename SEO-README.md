# Otimizações de SEO Implementadas - IARTES

## 📈 Melhorias Implementadas

### 1. Meta Tags Otimizadas
- **Title**: Título descritivo com palavras-chave principais
- **Description**: Descrição atrativa de 155 caracteres com informações relevantes
- **Keywords**: Palavras-chave estratégicas relacionadas ao projeto
- **Author**: Identificação da UFAC como autor
- **Robots**: Configurado para indexação completa
- **Language**: Definido como pt-BR

### 2. Open Graph (Facebook/LinkedIn)
- Configuração completa para compartilhamento em redes sociais
- Imagem, título e descrição otimizados
- Locale configurado para Brasil

### 3. Twitter Cards
- Meta tags específicas para Twitter
- Formato de card com imagem grande
- Título e descrição otimizados

### 4. Schema.org (Dados Estruturados)
- Marcação JSON-LD para EducationalOrganization
- Informações sobre o curso e a universidade
- Endereço e localização estruturados

### 5. PWA (Progressive Web App)
- Arquivo manifest.json criado
- Meta tags para aplicativo móvel
- Ícones e cores do tema configurados

### 6. Arquivos de SEO Técnico

#### robots.txt
- Orientações para bots de busca
- Permissões e restrições de crawling
- Referência ao sitemap

#### sitemap.xml
- Mapa do site com todas as páginas
- Prioridades e frequências de atualização
- Datas de última modificação

#### .htaccess
- Compressão GZIP habilitada
- Cache de arquivos estáticos
- Configurações de segurança
- URLs amigáveis (sem .html)

### 7. Canonical URL
- URL canônica definida para evitar conteúdo duplicado
